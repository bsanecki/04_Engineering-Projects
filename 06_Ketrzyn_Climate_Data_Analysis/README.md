# Kętrzyn Climate Data Analysis (1981-2024)

## Project Overview

An exploratory climatological study based on historical meteorological observations from the **Kętrzyn weather station in Poland**. The project uses daily and synoptic datasets covering the period 1981-2024.

The collected data provides a basis for examining long-term weather conditions, seasonal variations and changes in selected meteorological parameters.

## Data Overview

| **Dataset** | **Description** | **Period** |
|---|---|---|
| `KETRZYN_DOBOWE_SD.xlsx` | Daily meteorological observations | 1981-2024 |
| `KETRZYN_DOBOWE_SDT.xlsx` | Daily supplementary meteorological observations | 1981-2024 (partial) |
| `KETRZYN_TERMIN.xlsx` | Synoptic meteorological observations | 1981-2024 |

## Scope of Analysis

- Air temperature and seasonal temperature variations.
- Precipitation and annual precipitation patterns.
- Sunshine duration and cloud cover.
- Wind speed and direction.
- Atmospheric pressure and relative humidity.
- Historical weather variability and long-term patterns.
- Basic data organization and quality assessment.

## Data Parameters

The datasets contain meteorological measurements and observations, including:

- Maximum, minimum and average air temperature.
- Ground-level temperature.
- Precipitation and sunshine duration.
- Snow cover and atmospheric phenomena.
- Wind speed, direction and gusts.
- Relative humidity and atmospheric pressure.
- Cloud cover and dew point.

## Data Files

The repository contains the original Excel workbooks used as the basis for the study.

## Technical Notes

The datasets cover different observation types and do not have identical periods of availability. Measurement status codes and missing observations should be considered when interpreting the data.

The original workbooks are retained as source material. Numerical fields and data formats should be validated before performing statistical calculations or drawing climatological conclusions.

This project is intended for educational and portfolio purposes. It does not constitute an official climatological assessment or forecast.
